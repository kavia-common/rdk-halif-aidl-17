# TEVDevice (VController) — Build Instructions

This repository builds the TEVDevice **VideoDecoder** stub service (`RDKVideoDecoderService`) using generated **RDK HALIF AIDL** C++ artifacts and **linux_binder_idl** (libbinder/service manager) for local Linux builds.

The build flow in this repository is driven by:

- `build.sh` (end-to-end build orchestration and staging)
- `aidl_lib/Makefile` (compiles generated AIDL `.cpp` into `libhal_aidl.so`)
- `CMakeLists.txt` (builds and installs the `RDKVideoDecoderService` binary and TEVDevice headers)

> Note: AVBuffer has been removed from this repository. Any legacy AVBuffer-only build instructions have been retired, and the `test/` directory currently contains a leftover sample file that still references AVBuffer headers.

## Prerequisites

### Host OS and base tools

A typical Linux development environment is expected, with:

- A C++17-capable compiler toolchain (e.g., GCC)
- CMake (minimum version set by this project: 3.8)
- GNU Make
- `git`

### linux_binder_idl (AIDL compiler, libbinder, service manager)

This repo expects you to have a built checkout of `linux_binder_idl`, providing:

- `aidl` compiler binary
- `servicemanager` and related binder runtime libraries and headers (installed into a `local/` directory in the linux_binder_idl tree)

By default, `build.sh` assumes `linux_binder_idl` is located next to this repository (one level up), in:

- `../linux_binder_idl/out/aidl`
- `../linux_binder_idl/local/`

You can override these locations using environment variables (see below).

### Network access for dependency cloning

`build.sh` will clone these repositories if they are not already present locally:

- `https://github.com/rdkcentral/rdk-halif-aidl.git` into `./rdk-halif-aidl`
- `https://github.com/rdkcentral/ut-core.git` into `./ut-core`

## Environment variables

`build.sh` supports these environment variables:

### linux_binder_idl locations (most important)

```bash
# Path to the AIDL compiler binary
export AIDL_BIN=/path/to/linux_binder_idl/out/aidl

# Directory containing linux_binder_idl runtime install outputs:
#   bin/ (servicemanager, etc.)
#   lib/ (libbinder, libutils, liblog, etc.)
#   include/
export LINUX_BINDER_OUT_DIR=/path/to/linux_binder_idl/local
```

If not provided, defaults are derived from `../linux_binder_idl` relative to this repo.

### Dependency versions (optional)

```bash
# ut-core tag (if unset, build.sh selects the latest git tag)
export UT_CORE_VERSION=4.7.3

# Git branch/tag for rdk-halif-aidl to clone
# (defaults to "main" if unset)
export RDK_HALIF_AIDL_VERSION=main
```

## Build

### What the build does

When you run `build.sh Target=<linux|arm>`, the script performs the following high-level steps:

1. Stages linux_binder_idl runtime into `build/usr/` (bin/lib/include)
2. Clones and configures `rdk-halif-aidl`, and generates AIDL C++ artifacts under:
   - `build/current/h` (headers; some generators may use `build/current/include`)
   - `build/current/cpp` (sources)
3. Builds the generated AIDL code into:
   - `build/usr/lib/libhal_aidl.so` (via `aidl_lib/Makefile`)
4. Clones and builds `ut-core`, and stages its headers/libs into `build/usr/` (best-effort based on ut-core version outputs)
5. Configures, builds, and installs this repository’s service using CMake:
   - CMake build directory: `build/tevdevice/`
   - Install prefix: `build/usr/`

### Linux target

```bash
./build.sh Target=linux
```

### ARM target

```bash
./build.sh Target=arm
```

> The ARM flow depends on how your toolchain and sysroot are configured for cross-compilation. `build.sh` passes `TARGET=arm` to `aidl_lib` and `ut-core`, but the exact compiler/toolchain selection is external to this repository.

## Outputs and layout

After a successful build, key directories are:

### Staging prefix: `build/usr/`

This is the “install/stage prefix” used by `build.sh` and referenced by `CMakeLists.txt`.

Typical contents:

- `build/usr/bin/`
  - `RDKVideoDecoderService` (installed by `cmake --install`)
  - linux_binder_idl tools (copied from `LINUX_BINDER_OUT_DIR/bin`)
- `build/usr/lib/`
  - `libhal_aidl.so` (built from generated AIDL sources)
  - binder runtime libs (copied from `LINUX_BINDER_OUT_DIR/lib`)
  - ut-core / ut-control libs (staged by `build.sh`, depending on ut-core version/build output)
- `build/usr/include/`
  - linux_binder_idl headers (copied from `LINUX_BINDER_OUT_DIR/include`)
  - ut-core headers (best-effort copy)
  - TEVDevice public headers (installed by `cmake --install`)

### AIDL-generated artifacts: `build/current/`

Generated by the `rdk-halif-aidl` CMake flow invoked from `build.sh`:

- `build/current/h/` (preferred generated header output)
- `build/current/include/` (alternate/legacy header output supported by `CMakeLists.txt`)
- `build/current/cpp/` (generated `.cpp` sources compiled into `libhal_aidl.so`)

### CMake build directory: `build/tevdevice/`

This is the build directory used for this repository’s CMake configuration/build.

## Clean

The build script supports:

```bash
./build.sh clean
```

This cleans AIDL lib objects/library and removes some staged outputs.

To remove *all* build outputs and checked-out dependency repos:

```bash
./build.sh dist_clean
```

This deletes:

- `build/`
- `rdk-halif-aidl/`
- `ut-core/`

## Running the VideoDecoder service (local/dev)

The built executable is:

- `build/usr/bin/RDKVideoDecoderService`

The service entry point calls:

- `RDKVideoDecoderManager::publishAndJoinThreadPool();`

Runtime configuration and/or invocation details beyond the stub startup are environment- and integration-dependent and are not fully defined in this repository.

## Notes on tests

There is a `test/` directory containing `test/RDKAVBufferService_test.cpp`, but it currently includes `<avbuffer/AvBufferManager.h>`. Since AVBuffer has been removed from this repository, this file should be treated as a placeholder/sample rather than a buildable test in the current repo state.
