# Indicator component (HALIF AIDL 17)

This folder contains the **Indicator HAL** AIDL interface sources (under `current/`) and an optional lightweight C++ client helper (under `client/`).

The repository-level build system supports generating C++ artifacts from AIDL using CMake. If your environment does not have `aidl` on `PATH`, you can point to a **prebuilt `aidl` binary** via `AIDL_BIN`.

## Layout

- `current/`  
  AIDL sources for the `indicator` module and its `current` version.
- `client/`  
  Optional C++ helper library that can be built alongside the AIDL generation (does not affect generation).
- `build.sh`  
  Convenience wrapper (mirrors TEVDevice workspace convention) that drives the repository root CMake with:
  - `AIDL_TARGET=indicator`
  - `AIDL_SRC_VERSION=current` (default)
  - optional `AIDL_BIN=/path/to/aidl`

## Build (AIDL generation + optional client)

From this directory:

```bash
# Option A: provide a prebuilt aidl compiler
export AIDL_BIN=/path/to/prebuilt/aidl
./build.sh

# Option B: pass as an argument
./build.sh AIDL_BIN=/path/to/prebuilt/aidl
```

Outputs are generated by the repo’s top-level CMake into:

- `../gen/indicator/current/` (default)
  - headers: `../gen/indicator/current/h/`
  - sources: `../gen/indicator/current/cpp/` (depending on generator configuration)

## Notes

- The underlying AIDL compilation is implemented in the repository’s `CMakeModules/CompileAidl.cmake`.
- The module-level `current/CMakeLists.txt` already forwards `AIDL_BIN` into the generation step when defined.
- If you only want AIDL generation (no C++ helper), you can ignore `client/`.
